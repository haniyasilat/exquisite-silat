# Exquisite Silat — Outfit Collage Blog

Outfit collages with shoppable Amazon links. Browse by style (Casual / Fancy / Modest) and season.

## Live site

After GitHub Pages is on, your site will be at:

`https://<your-username>.github.io/<repo-name>/`

## Local preview

```powershell
cd "path\to\this\folder"
python -m http.server 8080
```

Open: http://localhost:8080/

## Fill in outfits later

Edit `links.json` (or `assets/js/outfits.js` for the live preview pages) — add collage images and Amazon links per piece.

## Pages

| File | What it is |
|------|------------|
| `index.html` | Home + hub squares |
| `hub.html` | Category grid (`?cat=Summer`) |
| `look.html` | Outfit collage + Shop the look |
| `about.html` / `disclosure.html` | About & Amazon disclosure |

Colors: light beige + dark ruby red.
